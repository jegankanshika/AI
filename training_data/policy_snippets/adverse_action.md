# Adverse Action Reason Codes (FCRA §615 / Reg B)

When a decline or counter-offer is issued, the memo must include one or more
codes from this list (top four contributing factors, ranked by SHAP magnitude).

| Code | Description |
|---|---|
| AA-01 | Credit score below program minimum. |
| AA-02 | Insufficient credit history (oldest trade < 12 months). |
| AA-03 | Recent delinquency on credit obligations. |
| AA-04 | Number of recent credit inquiries. |
| AA-05 | Revolving utilization too high. |
| AA-06 | Debt-to-income ratio exceeds program maximum. |
| AA-07 | Insufficient verifiable income for requested amount. |
| AA-08 | Employment tenure below program minimum. |
| AA-09 | Public record (bankruptcy / lien / judgment). |
| AA-10 | Loan-to-value exceeds program maximum (secured products). |
| AA-11 | Collateral does not meet program criteria. |
| AA-12 | Unable to verify identity. |
| AA-13 | Application incomplete (missing stipulations after 30 days). |
| AA-14 | Adverse external data (e.g., OFAC, fraud flag). |

**Prohibited basis** (must never appear as a reason): race, color, religion,
national origin, sex, marital status, age (with limited Reg B exception), or
receipt of public assistance.
